# Instrucciones locales de L08

- Fuente académica bilingüe de un caso sintético de 400 pedidos; no atribuir sus cifras a un socio.
- Mantener un único recorrido activo por audiencia: estudiante para extensos y docente para compactos.
- Cualquier cambio numérico debe contrastarse en tres scripts, dos libretas, dos presentaciones y el espejo inglés.
