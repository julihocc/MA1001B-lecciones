# L08 · study package

This package contains an extensive deck, an executed extensive notebook, three standalone scripts, and their three figures. The 400 orders are synthetic and do not describe any company.

Read the PDF to study the rules. The notebook runs top to bottom on Python 3.11 with pandas, numpy, matplotlib, and IPython; it needs no external files or network. Each script shows one complete increment and writes a PNG to figures/.

The conceptual source is OpenStax, Introductory Business Statistics 2e, sections 3.1 and 3.3, CC BY-NC-SA 4.0. No graded assessment items appear here.
